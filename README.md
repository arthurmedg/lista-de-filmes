# Minha Lista de Filmes 🎬

Atividade de React para treinar componentes, props e useState.

## 📌 O que a aplicação faz:
- Mostra uma lista de filmes com título, gênero, ano e status.
- Permite adicionar novos filmes com um formulário simples.
- Permite marcar e desmarcar filmes como assistidos.
- Permite remover filmes da lista.
- Mostra contadores em tempo real (total, assistidos e pendentes).
